# Эмулятор командной строки

Учебный проект по дисциплине «Конфигурационное управление».
Вариант №5. Программа имитирует небольшую UNIX-подобную командную
строку и работает с виртуальной файловой системой (VFS).

VFS загружается из папки пользователя в память при запуске. Команды
работают только со словарём в памяти: реальные файлы и папки VFS во
время работы программы не изменяются.

## Возможности

Приложение имеет графическое окно Tkinter. Заголовок использует
реальные имя пользователя и имя компьютера: `Эмулятор - [user@host]`.

Поддерживаются параметры командной строки:

- `--vfs ПУТЬ` — путь к папке, из которой загружается VFS;
- `--script ПУТЬ` — путь к стартовому скрипту.

Если `--vfs` не указан, создаётся небольшая VFS по умолчанию. При
запуске в окне выводятся значения обоих параметров. Стартовый скрипт
выполняет команды по очереди, пропускает ошибочные строки и сообщает
их номера. Строки, начинающиеся с `#`, считаются комментариями.

Перед разбором команды раскрываются переменные окружения реальной ОС,
например `$HOME`.

## Команды

| Команда | Назначение |
| --- | --- |
| `ls [путь]` | Показывает содержимое папки или имя файла. |
| `cd [путь]` | Переходит в каталог; без аргумента переходит в корень VFS. |
| `echo [текст]` | Выводит переданный текст. |
| `head [-n число] файл` | Выводит первые 10 строк файла или указанное число строк. |
| `mkdir путь` | Создаёт пустую папку только в памяти VFS. |
| `exit` | Закрывает окно эмулятора. |

Пути могут быть абсолютными, например `/home/alex`, или относительными,
например `docs`. Поддерживаются `.` и `..`.

## Основные функции

`write()` выводит строку в окно. `load_dir()` копирует папку с диска в
словарь VFS. `current_path()`, `resolve_path()` и `get_node()` помогают
работать с текущей папкой и путями внутри VFS.

`ls()`, `cd()`, `echo()`, `head()`, `mkdir()` и `run_command()` реализуют
команды эмулятора. `expand_vars()` и `parse()` раскрывают переменные среды
и разбирают строку. `run_script()` выполняет стартовый сценарий, а
`on_enter()` запускает команду, которую пользователь ввёл в окно.

`mkdir()` создаёт пустой словарь внутри VFS. Поэтому новая папка видна
только до закрытия эмулятора и не появляется на настоящем диске.

## Структура проекта

```text
src/emulator.py             исходный код программы
tests/scripts/              стартовые сценарии для этапов 1–5
vfs/                        VFS с тремя уровнями вложенности
vfs_files/                  VFS с несколькими файлами
vfs_minimal/                минимальная VFS
run.bat                     основной запуск этапа 5
run_*.bat                   сценарии запуска и проверки
```

## Требования

Нужен Python 3.10 или новее. Tkinter обычно устанавливается вместе с
Python для Windows. Внешние библиотеки не используются.

## Запуск

Основной вариант запуска в Windows:

```bat
run.bat
```

Или из командной строки:

```bat
python src\emulator.py --vfs vfs --script tests\scripts\test_stage5.txt
```

Для интерактивного режима без параметров:

```bat
python src\emulator.py
```

## Проверка

Папка `tests` содержит стартовые сценарии с командами и ошибками. Они
запускаются через `.bat`-файлы. Дополнительные сценарии можно запускать
двойным кликом:

- `run_default.bat` — VFS по умолчанию;
- `run_script.bat` — стартовый скрипт;
- `run_vfs.bat` — загрузка основной VFS;
- `run_errors.bat` — ошибки параметров и скрипта;
- `test_vfs_minimal.bat` — минимальная VFS;
- `test_vfs_files.bat` — несколько файлов;
- `test_vfs_deep.bat` — вложенная VFS;
- `test_vfs_errors.bat` — ошибки загрузки VFS;
- `run_stage4.bat` — команды этапа 4;
- `run_stage5.bat` — команда `mkdir` этапа 5.

## Примеры

```text
/$ ls
home/
readme.txt

/$ cd home/alex
/home/alex$ mkdir projects
/home/alex$ ls
notes.txt
projects/

/home/alex$ head -n 1 notes.txt
Мои заметки
```

После закрытия программы папка `projects` не появится на диске, потому
что `mkdir` меняет только VFS, находящуюся в памяти.
